# Jenkins输入卡片

> 早期独立模块说明，保留兼容接口与历史验证。当前 Bot 构建和真实双包交付见[当前实现](16-双版本构建确认与派发.md)；本页“未部署”等描述仅对应当时模块，不代表当前 Bot 状态。

同一张卡片只保留两个输入框：**本次uroad分支链接**和**APP_VERSION多行框**，没有预填按钮。

- 再次使用：自动带出本人上次确认的组件配置，包括自行追加的组件，可以直接修改。
- 首次使用：显示conan_shared、uroad_m100、dag_compiler三条固定引用格式，版本为空，由用户填写。
- 分支每次明确提供。换分支时，历史版本只是编辑起点，不自动认定与新源码匹配。
- 点击“检查参数”后显示错误或确认按钮。只有“确认并保存配置”才更新本人默认配置；未确认修改不覆盖历史。

首次多行框为：

```text
conan_shared/@livc/release-schu
uroad_m100/@livc/stable
dag_compiler/@livc/stable
```

直接在斜杠后填版本，可在末尾追加 `组件/版本@用户/通道`，每行一条。缺版本、范围版本、重复组件或固定通道错误会提示修改，输入不会被静默截断。飞书单框最多1000字符。

**当前交付是独立源码模块，不是已上线的Bot入口。** 它按租户和本人身份保存确认配置，身份由受信宿主取得；不会读取其他用户的默认值。组件是否存在、源码和依赖匹配、OFF/ON引用及Jenkins参数仍须后续核验。保存配置不会生成APP或触发任何构建。

确认输入现可通过独立接口连接两版参数计划；构建后的模式清单按实际编号明确区分普通OFF、评测ON。代码接口和执行边界见[双包交付](13-Jenkins双包交付.md)。未部署真实回调，台架流程保持原状。

代码、调用接口及离线预览命令见[模块说明](../modules/jenkins-input-card/README.md)。本次未接入台架网关、任务队列或Runner，不修改原Jenkins流水线、不发送飞书消息。接入时另行配置受信回调与私聊卡片投递，个人配置库不随Git发布。

2026-11-12新增模块的22项离线测试通过，包含首次/再次使用、修改追加、未确认不保存、跨用户/租户隔离、旧卡及并发更新、重复回调和禁止外部调用。离线卡片结构检查不代替真实飞书客户端渲染或线上回调联调。
