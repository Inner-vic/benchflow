# 公开副本与脱敏说明

公开仓库由工作副本单独导出，以独立初始提交发布，不包含此前私有仓库历史。此前保留的 GitHub 私有备份仓库已删除；本地台架工作副本继续用于原设备环境维护。

- 内网地址与网段改为文档专用地址；环回地址保留其本机语义。
- 公司域名、平台入口、个人与共享账号、用户目录、共享卷标识替换为示例。
- 真实车辆及记录场景替换为演示标识；真实产物哈希替换为示例身份。
- 内部构建补丁、原始回放源码快照与真实数据清单不发布。
- 缓存、运行记录、设备实配、二进制、数据集、认证文件与本地环境不发布。
- 公开 Git 提交不携带原作者个人邮箱。

示例与生产输入不具备对应关系。保留的历史模块名称仅说明适配位置，不提供内部平台接入能力。示例地址、路径和账号不能作为真实设备配置使用。

扫描覆盖公开文件及可达 Git 历史中的域名、地址、账号、车辆标识、个人路径、凭据特征与文件清单。离线测试检查脱敏后的逻辑一致性，不能替代真实环境验收。后续提交仍应遵循相同公开边界。
