# 架构：统一入口、确定性执行与独立后处理

当前业务链路详见[当前系统](current-system.md)。原版本的规划器/锁/收据仍是执行基础；系统上层已增加飞书统一入口，不能再只画“个人助手直接调用 Runner”。

## 分层与部署

| 层 | 部署与实现 | 职责 |
| --- | --- | --- |
| 统一交互 | 个人电脑 CC Connect、Codex、`gateway/bench_gateway` | 本人私聊、受限意图解析、同一材料/任务卡、版本确认 |
| 准备和调度 | 网关持久库与单调度器 | 锁外准备、冻结候选、硬件 FIFO、独立评测/归档/到点状态 |
| 执行协调 | 工作站固定网关组件与原 Runner | 核对候选/工具身份、Job/Profile、按需安装、台架 JSON 锁 |
| 硬件事务 | 适用本次软件的 adapter 与台架 | 小场景和全量各自回放、恢复、核验；全量内部批次执行 |
| 产品与后处理 | 工作站 Tasks/Cache、云端或历史评测后端 | 产品交付、任务 GT 关联、原生评测、TXT 或到点 XLSX |

共享工作站不部署 AI。网关的本人归属和目录检查不等于共享 Linux 账号下的系统级隔离。

## 主链路和两个关键边界

材料输入先形成草稿，卡片“确认执行”绑定当前版本，随后检查/绑定才入 FIFO。准备不占台架锁。候选身份包括软件、SO、YAML、场景、回放方式及适配实现；入队前修改使确认和旧绑定失效，入队后冻结材料不随个人“最新版”变化。

`executor.py` 对每个新任务先派发 `<run>-smoke`，验证后才派发完整 `<run>`。预检与全量是两个 Runner 事务，全量重复包含预检场景；安装仍由既有安装器管理。入口 FIFO 不是覆盖全部阶段的一次连续硬件锁。匹配当前正式文件时可省安装，匹配本人成功装配时可省下载/装配，本次预检保留。

回灌和恢复、产品核验成功后，`core.py:complete_replay` 原子交接独立 `postprocess` 队列。原任务可处于 POSTPROCESSING，硬件可服务下一项。后处理失败保留成功回灌；归档也可独立完成，不扩大为硬件失败。

## 数据与配置的变化

数据源按场景级校验小 manifest 与入口归属，常规不逐帧扫描。云端路径仅下载选中 original 的协议必需文件到工作站，GT 留云端。流式与逐帧选择随任务冻结，使用任务专属客户端派生，不修改共享 Recorder/Runner。

用户 YAML 先产生任务候选；适配器再应用固定回放/输出覆盖并保存其来源。保留原 YAML 不表示台架执行内容逐字不变。软件和库静态通过不保证 ABI、实际加载或回放协议兼容。

新评测后端按登记生效时间选择，历史任务不换后端。`cloud_truth.py` 把显式数据根/GT根绑定到本任务，完整场景精确匹配，不把 V151 当全局默认。`evaluation_direct.py` 与云端常规评测使用路径/报告检查，输入内容未做全文哈希；固定工具、配置、小清单、TXT、场景覆盖与有效样本仍检查。Runner 产品内容身份与这项精简是不同边界。

## 到点精度与交付

当前到点精度只由本人已交付原任务卡的按钮触发。`arrival_analyses` 保存独立请求、计算与报告状态，绑定原 Tasks CSV/XCP；不需要 LPAI，不持台架锁，不为缺 CSV 补跑。原项目 CLI 开关仍保留作兼容，不能当作飞书入口的现行交互。

普通评测交付原始 TXT；到点交付 XLSX 和分析计划；软件发版文档、PCM 双包仍是配套工具。在线文档发布并未自动加入主链路。

## 恢复与信任

入口 FIFO 确定顺序，工作站 JSON 锁保护跨入口硬件互斥。未知硬件结果保留 NEEDS_REVIEW 并阻止新硬件变更，不能用服务重启、超时或 PID 消失清锁。首次未派发且有独立正面证据时才允许任务局部失败；已经派发的预检/全量只从原收据核验续接。

评测结果不明只续收原 attempt，到点未知不自动重算，报告发送未知不重复发送。云端请求签名与固定接收端约束授权；消息数据不携带任意命令。原 Job/Profile 仍使用受控命令集，Profile 本身也需审阅。

## 源码范围

内部仓库的 `gateway/` 保存统一入口独立项目的源码快照；公开版不分发该目录。`automation/` 是原 Runner 与工具；`skills/` 是原执行、离线评测、报告与双包契约。网关实际使用 `gateway/vendor/` 固定上游字节，不因本仓库源码变化自动升级生产依赖。当前源码映射、验收范围和迁移限制见[当前系统](current-system.md)，下层 release 与 current 结构见[Runner 说明](workstation-runner.md)。
