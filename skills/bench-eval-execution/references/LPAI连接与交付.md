# 可选计算环境：从已验证产品继续

历史适配接口保留 `lpai` 名称，公开副本不包含原平台入口、账号、共享卷或评测工具。新的计算平台需要独立配置与验证。

1. 通过平台提供的当前 SSH 端点和个人授权建立独立连接，核对主机指纹。认证材料留在个人环境。
2. 选择已经通过生产收据、当前清单与内容身份验证的工作站产品。
3. 确认目标位置，保留冲突和 partial 状态，不静默覆盖已有不同产品。
4. 发布并核对副本身份。发布失败保留工作站产品，只处理下游故障。
5. 确认本次场景对应的真值布局、内容身份与评测器实际读取规则。目录版本名不能证明真值匹配。
6. 创建独立评测尝试，保存配置、执行路径、输入身份、日志、退出码和报告；重试保留旧证据。
7. 检查匹配帧、有效样本及任务覆盖，再报告指标。退出码为零不能证明算法达标。

共享产品与个人评测空间分别维护。共享 Linux 账号的逻辑任务归属不构成操作系统级隔离，实际部署应配置必要的账户与文件权限。
