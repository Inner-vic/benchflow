# GitLab交接范围

当前仓库为developer-handover/bench-evaluation。以[当前文档入口](../../../docs/README.md)、[部署清单](../../../docs/09-部署与接手清单.md)和[收录来源](../../../docs/10-仓库收录与来源.md)为准；旧ZIP说明、文件清单和validate_package.py不适用于本库。

| 目录 | 内容 | 使用方式 |
|---|---|---|
| windows | 连接/解析源码、Schema、单步迁移工具 | 新Windows迁移主体，不含CC/适配器二进制和私有认证 |
| workstation/gateway | Linux业务源码、解析Skill、vendor和测试 | 核对参考，不能全覆盖生产 |
| workstation/runner-reference | 原Runner/扩展参考 | 保留完整入口，不绕扩展 |
| cloud | 原受控接收端、分清版本的profile和评测器源码 | 与PCM测试1现场专属运行协议区分 |
| config | 非敏感参考和源码选择清单 | 不是完整可运行生产配置 |
| docs、skills | 当前流程、设备、认证、交接和详细手册 | 从START_HERE开始 |
| tools/check_repository.py | 静态发布检查 | Python/JSON/链接及文件/高置信度凭据边界，无生产动作 |

不包含runtime/state、SQLite、APP/SO、数据集、GT、预测、报告、日志、Cookie、Token、密码、私钥、Docker镜像、Recorder大依赖或其他项目完整业务。源中保留认证字段名及公开路径，不保存认证值。

本轮按已跟踪源码整理，排除23个生成/调试文件，审阅现网源码差异并补齐新增依赖；不重构运行路径、不改工具摘要、不改生产配置或重启。日后接手以实际源码及新鲜任务状态为准。静态检查不能替代真实确认和设备验收。
