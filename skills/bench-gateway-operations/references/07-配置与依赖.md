# 配置字典、代码入口与依赖

> 当前流程、现场状态和问题以[2026-11-05文档入口](../../../docs/README.md)为准。本页保留设备配置细节；注明11月3日的观察和ZIP交付范围属于历史快照。

## 两台机器配置必须分开

Windows模板是`windows/config/gateway.example.json`，角色ai-client；Linux参考是`config/workstation-public-reference.json`。参考文件保留了生产路径和组件摘要，但未包含完整认证/签名配置，不可直接覆盖现有gateway.json。Linux安全示例默认simulate/live_enabled=false；开真实执行须先完成项目既有验收和本次授权，不自动接管。

| 配置组 | 关键字段 | 说明 |
|---|---|---|
| 设备角色 | deployment_role、ai_backend、workstation_local_execution | Windows解析；Linux本地业务执行；不能混用 |
| 入口 | feishu_app_id、cc_project、desktop_bridge_enabled、desktop_bridge_generation、cc_binary | Linux cc_binary是desktop_bridge_observer，不是真正CC；真实Windows binary另配 |
| SSH | workstation、remote_project_root、remote_python、desktop_ssh_* | 新机按本机路径设置；Linux内部封装允许本地执行 |
| 业务存储 | state_root、remote_users_root、central_datasets_root、dataset_catalog | 默认分别是集中state、users、datasets及数据源登记 |
| 受理与确认 | provision_from_feishu、require_material_confirmation、auto_execute_on_complete、inline_material_card | auto_execute_on_complete表示确认后的串联，不是收齐材料自动执行 |
| 解析/通知 | parser_timeout_seconds、poll_seconds、task_cards_enabled、unified_status_cards、card_callbacks_enabled | 当前复杂解析75秒、轮询3秒；通知失败不触发重跑 |
| APP下载 | download_hosts、livc_app_base_url、material_download_timeout_seconds | HTTPS/域名白名单；完整URL或已支持CCU文件名；默认下载300秒 |
| 编译 | m100_build_enabled及m100-build-profiles.json | 按APP SHA和受控源码/锁，不给未知APP套2737默认配方 |
| 回放 | adapter_templates、default_adapter_template、workstation_runtime_release、yaml_runtime_archive | 精确工具摘要与历史资格；保留原Runner扩展 |
| 评测 | default_evaluator、cloud_evaluation_profiles | 新任务按注册时间选最新已生效云端策略；历史策略append-only |
| 数据 | require_explicit_dataset、cloud_dataset_enabled、cloud_dataset_volumes | 无默认PCM/V151；允许输入卷须显式配置UID |
| 云端 | cloud_sdk_python、cloud_node_binary、cloud_browser_autostart | 当前SDK/system Python3.8，浏览器启动false；签名私有配置不在包内 |

`cloud_dataset_max_bytes=64GiB`、`cloud_dataset_timeout_seconds=3600`是当前自动输入准备限额；不是“所有数据集都能任意大下载”。附件接收默认上限128MiB。11月4日已部署8MiB Range分片，104,331,960字节原生附件完整下载耗时28.721秒并关联材料。官方资源API允许100MB及以上文件分片，每片不超过32MB；不把机器人上传API限制套用到用户聊天附件。超入口上限用工作站路径或链接；单次实测不等于长期成功率。

## M100编译与eval_dump

编译需要本APP对应源码及准确提交/修改、源码build/conan.lock、SDK/function-message/雷达等开发包和工具链，而不仅是上传的libxlidar.so。开发包包含头文件；运行SO与开发头文件不是同一个文件。

集成Lockfile不是源码构建锁本身。11月5日已接通自动流程：原APP文件名/构建号→精确集成锁和Conan修订→源码提交→构建依赖闭包；使用独立快照及已核验通用工具链，不绑定旧APP配置。2880关闭WITH_EVAL_DUMP真实纯编译及静态检查通过，尚未实机。没有匹配工具链、制品或接口时明确停止，要求手动编译提交配套SO，不随意换版本。

WITH_EVAL_DUMP是编译能力；common_param.yaml中的eval_dump.enable是运行开关，二者共同控制落盘。11月6日起遵从所选APP官方ON/OFF构建参数，不按任务目标切换宏或运行配置。仅回放跳过指标计算：ON且落盘开启时回收预测结果，OFF且落盘关闭时交付日志与完成恢复证据。评测要求官方ON版及配套落盘配置，冲突提前提示。input_traj和sus_preview_timeline.csv仍须按实际源码、分项配置和真实产物核验。中断时证据不足继续待核验，不自动重放。详见[当前M100规则](../../../docs/11-M100官方构建与自动编译.md)。

## 包内与包外

Git仓库有两端Python源码、Runner参考和云端接收程序。补丁Windows CC/适配器、原生评测器二进制和动态库未进入Git，需从受控已有部署取得并核对摘要。此前ZIP曾携带部分二进制，不能将ZIP说明直接用于Git。包外保留操作系统解释器、Docker镜像、Recorder大依赖、LPAI运行实例、认证、业务数据库、APP/SO、数据集和结果。没有这些既有依赖，不能称本包可在一台空电脑上离线复原四设备系统。

RoadModel是同Bot的独立业务依赖：网关固定发布路径加载pcm_eval，板端应以roadmodel_hardware进入同一队列。本次源码已核对路径更新为evaluation-native-20261105-r2；旧F12审计属于此前发布，当前接入须另核对，不能仅凭适配器存在宣称全接通。CPU/云端阶段不占台架；不覆盖其模型/原脚本/已完成帧，不另起第二硬件调度器。
