# 台架评测部署与运维

先读[现状与限制](references/09-现状与限制.md)，按实际任务选择参考；本Skill随完整交接包使用，不覆盖生产JSON解析Skill。

- 理解链路：[架构与工作流](references/01-架构与工作流.md)、[目录与文件管理](references/02-目录与文件管理.md)。
- 换Windows：[迁移交接](references/03-Windows迁移交接.md)。先准备后切换，连接与解析两个后台任务均须处理；只停止解析器不能释放CC租约。
- Linux维护：[工作站手册](references/04-Linux维护与重建.md)、[配置与依赖](references/07-配置与依赖.md)。保留原Runner扩展，核对现用监督器与systemd，不能双开。
- LPAI：[挂载与调用](references/05-LPAI挂载与调用.md)、[认证与授权](references/06-认证与授权.md)。不默认V151，GT随任务数据源关联；预测写独立输出卷；账号与心跳分层诊断。
- 验收/回退：[运维手册](references/08-运维验收与回退.md)；包范围见[文件整理](references/10-文件整理与交付范围.md)。

使用当前源码、配置和新鲜只读证据判断状态，不以历史文档或ready/静态通过宣称实机成功。业务数据只在Linux，Windows只放程序/静态配置与受控连接元数据。维护前核对所有项目在途活动、备份、审查外部改动；文档变化不重启入口。

真实执行只接受用户在有效材料卡上的确认。保持本人资产、冻结材料、统一硬件FIFO和原子JSON锁；正常忙等待，未知执行不自动重跑/清锁，不重复已完成帧。通知或评测失败只续收原任务。

`pending/`是未部署候选；2880编译成功不等于真实回放通过。当前主认证失效、实例停止、缺GT或设备身份不明时明确报告具体缺口，不绕过平台或浏览器权限。
